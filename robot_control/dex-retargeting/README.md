# Bundled Dex Retargeting

This bundled copy is adapted from a [Unitree fork](https://github.com/silencht/dex-retargeting) of [Dex Retargeting](https://github.com/dexsuite/dex-retargeting) by Yuzhe Qin.

Follow the [HTD controller installation](../README.md#install-from-the-repository-root)
for this bundled copy. That setup supplies Pinocchio and its CasADi bindings
through conda and installs this package with `--no-deps` to preserve those
bindings.
